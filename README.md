# Sphere Cortex dev suite

Sustainable software development suite shell for cortex.thesphere.online.

Deployed on Vercel from this repository. Wallet connect is client-side MetaMask only.
Fiat rails (Lloyds, Revolut, Apple Pay, Visa, Mastercard, direct debit) are documented integration points and are not live until you add your own regulated provider credentials in Vercel environment variables.
