cortex.thesphere.online · sustainable software suite

Cortex development suite

Control surface for the Sphere stack. This deployment is the shell. Payment rails and model keys stay in your own merchant and API accounts. No card numbers, bank logins, direct-debit mandates, or wallet seeds are collected here.

Vercel

Linked deploy target for this repository.

ChatGPT / model API

Needs an OpenAI key in Vercel env as OPENAI_API_KEY. Not stored in the repo.

MetaMask / BNB

Browser wallet only. Chain id 56 is suggested if the user approves.

Not connected.

Lloyds

No public deploy API. Use Open Banking via a regulated provider you contract.

Revolut

Merchant API key required. Do not paste it into chat.

Apple Pay

Requires a verified domain, merchant id, and a processor such as Stripe or Adyen.

Visa / Mastercard

Acquiring is through a PSP. This site is not a card processor.

Direct debits

UK Bacs via a sponsor such as GoCardless. Mandate setup stays on their hosted flow.

What still has to be done by you

  1. Point cortex.thesphere.online at this Vercel project.
  2. Add processor keys in Vercel project settings, not in git.
  3. Complete KYC with the payment provider before taking money.
